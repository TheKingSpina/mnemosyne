# Code of Conduct

Mnemosyne follows the Contributor Covenant 2.1.

## Our standards

- Be respectful, patient, and constructive.
- Critique ideas and code, not people.
- Avoid harassment, threats, discrimination, and personal attacks.
- Protect private memory, credentials, and unpublished security findings.
- Welcome newcomers and explain technical decisions clearly.

## Reporting

Report conduct concerns privately to the project maintainer through the private security or contact channel described in the repository. Do not publish personal information or private reports in a public issue.

The full text is available at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
